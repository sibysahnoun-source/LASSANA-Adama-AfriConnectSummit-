# LASSANA-Adama-AfriConnectSummit-# 🌍 AfriConnect Summit 2026

Bienvenue sur le dépôt du site web officiel de l'**AfriConnect Summit 2026**, un événement technologique et entrepreneurial majeur réunissant les acteurs de l'innovation en Afrique à Dakar, Sénégal.

---

## 📌 Présentation du Projet

Ce projet est une plateforme web responsive, interactive et moderne conçue avec les technologies fondamentales du Web (HTML, CSS, JavaScript). Elle permet aux participants de consulter le programme, de découvrir les intervenants et de s'inscrire au sommet.

### ✨ Fonctionnalités Principales
* **Page d'Accueil (`index.html`) :** Présentation du sommet, compte à rebours dynamique en temps réel jusqu'à l'événement et statistiques clés.
* **Programme (`programme.html`) :** Planning interactif avec filtres par jour et présentation des thématiques principales.
* **Intervenants (`intervenants.html`) :** Galerie d'experts avec photos stylisées, rôles et filtres par domaine (IA & Tech, Business, Design, Data).
* **Inscription & Contact (`contact.html`) :** Formulaire complet avec validation côté client (longueur minimale du message, choix de participation, pays).
* **Mode Sombre (Dark Mode) :** Basculement dynamique entre le mode clair et le mode sombre avec persistance du choix de l'utilisateur (`localStorage`).
* **Design Responsive :** Interface adaptée à tous les écrans (mobile, tablette, ordinateur).

---

## 🛠️ Technologies Utilisées

* **HTML5 :** Structuration sémantique des pages web.
* **CSS3 :** Flexbox, CSS Grid, variables CSS et styles dynamiques pour le mode sombre.
* **JavaScript (ES6) :** Manipulation du DOM, compte à rebours, filtres et gestion du `localStorage`.
* **Git & GitHub :** Gestion du contrôle de version et hébergement du code.
